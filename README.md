# DevOps CI/CD and Infrastructure Automation

## Project Overview

This project demonstrates hands-on implementation of DevOps practices across source control, CI/CD, containerization, orchestration, and infrastructure automation.

The project involved working with Git and GitHub for version control, Jenkins for CI/CD automation, Docker for containerization, Kubernetes for container orchestration, and Terraform and Ansible for infrastructure and configuration automation.

## DevOps Workflow

**GitHub → Jenkins → Docker → Kubernetes**

**Terraform / Ansible → Infrastructure & Configuration Automation**

## Technologies Used

- Git
- GitHub
- Jenkins
- Docker
- Kubernetes
- Terraform
- Ansible
- AWS

## Key Areas

### Git & GitHub
- Practiced Git-based version control and branching workflows.
- Worked with repositories, branches, commits, merges, and remote repositories.
- Used GitHub to manage and store project files.

### Jenkins & CI/CD
- Created Jenkins pipelines to automate build and deployment workflows.
- Worked with Jenkins Pipeline configuration.
- Practiced triggering automated workflows from source-code changes.

### Docker
- Created Dockerfiles for containerized applications.
- Built and managed Docker images and containers.
- Worked with container ports and application configuration.
- Published container images to Docker Hub.

### Kubernetes
- Practiced deploying containerized applications using Kubernetes.
- Worked with Pods and Deployments.
- Used `kubectl` to manage and scale Kubernetes workloads.

### Terraform
- Practiced infrastructure provisioning using Infrastructure as Code.
- Defined cloud infrastructure using Terraform configuration files.

### Ansible
- Practiced configuration management and automation using Ansible.
- Worked with playbooks to automate system configuration tasks.

## Learning Outcomes

- Gained hands-on experience with the DevOps lifecycle.
- Practiced CI/CD automation using Jenkins.
- Learned containerization with Docker.
- Worked with Kubernetes for container orchestration.
- Practiced Infrastructure as Code using Terraform.
- Practiced configuration management using Ansible.
- Strengthened Git and GitHub workflow knowledge.
